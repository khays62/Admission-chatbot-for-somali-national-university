# Qaab-dhismeedka Foomka Codsiga SNU (Somali)

## Ujeeddo
Mashruuca admission chatbot-ka waa in uu ka caawiyo ardayga inuu buuxiyo foomka codsiga SNU si tartiib tartiib ah, oo uu ku weydiiyo su'aalaha hal-hal, iyo uu ku keydiyo xogta si fudud.

## Xigasho
Xogta ugu muhiimsan ee ay ku salaysan tahay qaabkan waxay ka timaadaa foomka codsiga ee SNU:
- https://student.snu.edu.so/admission/home

## 1. Qaybaha Foomka

1. Macluumaadka Ardayga

5. Macluumaadka Masuulka
6. Bixinta Lacagta Codsiga
7. Dukumentiyada Loo Baahan Yahay

## 10. Qaababka Xogta Loogu Keydin Karo Frontend-ka
Hadda annaga oo aan weli DB isticmaali karin, waxaa jira qaabab kala duwan oo aan u keeni karno frontend-ka.

### 10.1 Local Storage
- Waa hab fudud oo kolay ah.
- Xogta waxaa la keydiyaa browser-ka si ku-meel-gaadh ah.
- Waxaa ku habboon tijaabo iyo prototype.

### 10.2 Session Storage
- Xogta waa ku-meel-gaadh oo ku xiran browser session-ka.
- Waxaa ku habboon haddii xogta la rabto in ay ka baxdo marka browser-ka la xiro.

### 10.3 In-memory state (React state)
- Xogta waxaa lagu hayaa kaliya markaa app-ka la furay.
- Waa hab aad u fudud laakiin ma sii hayn karo xogta marka page-ka la refresh gareeyo.

### 10.4 JSON file export
- Waxaa laga soo saari karaa xogta oo la keydin karaa file ahaan `.json`.
- Waa hab wanaagsan haddii aan rabno in aan xogta u qaadno backup ama tijaabo.

### 10.5 IndexedDB
- Waa hab xoog leh oo browser-ka ku kaydiya xog badan.
- Waa ku habboon haddii aan rabno in aanu xogta kaliya local storage ku qornin, laakiin ay wali browser-ka ku jirto.

## 11. Talo Bixinta Ugu Fiican
### Habka ugu fiican ee hadda loogu isticmaali karo
Haddii aan rabno in aan si fudud ugu shaqeyno frontend-ka, waxaan ku talinayaa:
- Isticmaal Local Storage si aad ugu keydiso xogta foomka ka hor inta aan DB la helin.
- Isticmaal JSON export si aad u backup gareyso xogta.
- Haddii waqti la siiyo, ku dar IndexedDB oo aad u keento xogta si badan.

### Sababta aan Local Storage doorbidayo
- Fudud yahay.
- Ma u baahna server.
- Aasaas wanaagsan oo prototype-ka ah.
- Waxtar leh markaa aan rabno inaan tijaabno flow-ka chatbot-ka.

## 12. Fikradaha Ugu Wanaagsan ee Mashruuca
### Habka 1: Frontend-only prototype
- Chatbot-ku wuxuu weydiistaa su'aalaha hal-hal.
- Xogta waxaa la keydiyaa Local Storage.
- Marka form-ka dhamaato, xogta waxaa la muujin karaa user-ka.
- Waxaa la soo saari karaa JSON backup.

### Habka 2: Frontend + simple backend later
- Xogta waxaa la keydiyaa Local Storage marka hore.
- Kadib backend-ka waxaa lagu dari karaa MongoDB.
- Maadaama code-ka loo qorsheeyay si modular ah, beddelka DB dambe waa fudud.

## 13. Talo Aan Ku Bixinayo
Haddii aad rabto in aad si degdeg ah u bilowdo, waxaan ku talinayaa inaad bilowdo sida tan:
1. Samee UI-ka chatbot.
2. Samee flow-ka su'aalaha hal-hal.
3. Keydi xogta Local Storage.
4. Samee summary page oo muujineysa xogta la soo uruuriyey.
5. Kadib markaa u beddel DB (MongoDB) haddii aad rabto in ay noqoto mashruuc dhab ah.
